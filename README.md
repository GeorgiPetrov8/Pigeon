# Pigeon

Pigeon is a Twitter-style social media platform built with PHP. Users can share short posts, interact with other people's content, and browse profiles, while administrators manage the platform through a dedicated admin center.

## Features

### Users
- Register and log in
- Create posts
- Delete your own posts
- Like posts
- View user profiles and their posts

### Admin center
- Dedicated admin area for platform management
- Moderate content and manage users

## Technology

- PHP (server-side logic)
- HTML, CSS (front end)
- Project folder: `ProjectPHP/`

## Getting Started

1. Install a local PHP environment such as XAMPP, WAMP, or use the PHP built-in server.
2. Clone the repository:
   ```bash
   git clone https://github.com/GeorgiPetrov8/Pigeon.git
   ```
3. Place the `ProjectPHP` folder in your web server's root directory (for example `htdocs` in XAMPP).
4. Start the server and open `http://localhost/ProjectPHP/` in your browser.
